# DemandDecisionLab 实操验收起步包

这是一组公开题面和小数据，自拟于2026-10-10，非雇主试题、课程原作业或认证考试。所有数据均为合成。题面及可手算的期望在CHALLENGES.json。

## 使用
1. 选择data、forecast、optimization或agent挑战。
2. 自己建立相应脚本/测试，允许AI辅助起草；审查代码并实际运行。
3. 保存命令、环境、commit、输出与AI辅助范围。
4. 对公开样例全通过后，完成题面列出的公开变式练习/现场调试答辩。
5. 在网站逐条填写验收证据；网站不自动执行代码，结果仍为自评。

## 不足
- 这些小样例只验证基本正确性，不能替代真实公开数据回测、性能/安全评测。
- mock Agent只证明协议和工程路径；不证明真实LLM成功率。
- 合成约束成本不证明真实商业节省。
- SQL无观测市场C的均值应为null；求和是否显示0须明确约定。
- data_invalid.csv的第6行是重复键，第7行计数缺失（含表头计行）。

## 公开题面不等于未见测评
以上题面、期望和变式都已公开，只用于练习。真正未见题需要复核者另外给数据/参数并记录现场完成过程；本包不能独立认证技能。
