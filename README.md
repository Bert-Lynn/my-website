## 现在怎么使用

1. 在“今日总览”点当前主按钮。首次先做30分钟航班比较：虚构A为980元/5.5小时，B为880元/7.5小时；预算内优先省时间，1000/900/800元应分别得到A/B/无结果。
2. 在自己的Python环境里实际运行，保存代码、命令、输出与卡点；遇到不会的再查对应资料。环境准备另算，30分钟不是完成保证，也不等于90分钟原课节完成。
3. 到“我的作品”按阶段标准保存“正在做”或“已完成”。下次从“今日总览”主按钮或“学习路线”回到首个未完成作品阶段。

当前Agent路线有20个参考课节、7项旧技能自查，六个模块课节数为4/6/2/3/3/2。自动测试提前到第3步；预测指标、区间估计和训练集防泄漏移到选学。原题、量表、ID和记录不变，不必先刷完旧预测练习才开始航班作品。

20课合计2340分钟（39小时）只是课内学习练习估计，不是新作品总工期。原100/50小时与150小时完整组合只用于历史DDL方案，不作为当前软件工期。每周通常6小时、最多8小时；论文投稿/返修周最多3小时。当前作品尚未建成，未来界面预览不代表已实现功能。

## 本地与云端进度

保留兼容键 `lin-ai-phd-roadmap-progress-v1`。未启用云端时，本机执行计划仍能保存。

`cloud-config.js` 配置所选 Supabase 项目的 URL 与 public/publishable key；严禁填写 service-role key。
`cloud-sync.js` 在启用后才加载 Supabase 客户端。云端需要先应用 `supabase/001_private_progress.sql` 并验证 RLS。

- 云端进度按认证账号隔离；访客不能读取其他账号进度。
- 用户可亲自在网站中注册同步账号；若需邮箱确认，验证后回到网站登录。该账号不同于 Supabase 管理后台账号。
- 首次登录不会自动上传本机旧记录；通过“合并本机已有进度”明确导入。
- 勾选和取消勾选均同步。离线修改保留在设备上，恢复后重试。
- 多设备版本冲突会提示选择，避免静默覆盖。
- 退出登录恢复本机访客进度，不将前一个账号进度混入其他账号。
- 状态分别显示本地、连接中、待同步、已同步、冲突与错误；未成功同步不会假报成功。
