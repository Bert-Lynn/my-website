## 顺延规则

- 计划从 2026.10 开始，依赖任务顺延一个月；2027.09 面试与实习投递目标保留。
- 所选月份显示该月计划及此前所有未完成任务，按原顺序优先补齐。日期变化不会自动勾选、删除或复制任务。
- 已完成历史任务可展开取消勾选；全年视图保留全部 41 项及原计划月份。
- 按 Asia/Shanghai 判断当前月份，超出计划末月后仍显示待办。
- 延续原有浏览器本地进度，不跨设备同步。

## 进度总览

- 全局完成率与三维进度只统计已勾选任务；每格代表一项，时间流逝不会增加完成率。
- 当前阶段由最早仍有未完成任务的阶段决定；论文、实习里程碑由对应任务独立判定。
- 可从优先待办跳到具体任务，也可筛选仅未完成项；随时回到本月。
- 勾选、取消勾选和重置会更新所有看板；同源浏览器标签页同步刷新。
- 存储不可用时会明确提示，避免误认为进度已保存。
