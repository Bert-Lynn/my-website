## 三层 Agent 学习进阶（公开只读计划）

`project-outline.growthLevels` 给出应用研发、检索与评测、后训练/RL三层。每层有起点、官方精确章节、具体练习、建议文件、检查方法与算力/费用门槛。项目页以三张折叠卡呈现；课程页把后续路线收在一个可选展开区。第一层对应既有WA4，后两层没有新云端键、完成按钮或百分比。

第二层在同一反馈项目比较TF–IDF/向量检索、重排与消融；第三层先PyTorch闭环和小规模SFT，再做独立成对回答的DPO，实际采样—奖励—参数更新的GRPO为受门槛限制的选修。DPO不等于在线RL，原反馈情绪标签不能冒充回答偏好。所有估时为先决条件满足后的规划，未购买API/GPU或启动训练；免费课程不保证免费算力。
